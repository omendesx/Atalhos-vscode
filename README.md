<p align="center">
Lista de atalhos de teclado úteis do Visual Studio Code.
Estes atalhos também podem ser utilizados no <b>IntelliJ IDEA</b> através do plugin <b>VSCode Keymap</b>.
</p>

---

<div align="center">

| Atalho                 | Função                                                     |
| ---------------------- | ---------------------------------------------------------- |
| `Ctrl + Shift + P`     | Mostrar Paleta de Comandos (Ex: Java: Create Java Project) |
| `F11`                  | Alternar tela cheia                                        |
| `Ctrl + = / -`         | Aumentar/diminuir zoom                                     |
| `Ctrl + ,`             | Abrir Configurações                                        |
| `Ctrl + ´`             | Abrir/fechar Terminal                                      |
| `Ctrl + F4`            | Fechar editor                                              |
| `Ctrl + Shift + N`     | Abrir nova janela                                          |
| `Ctrl + Shift + W`     | Fechar janela                                              |
| `Ctrl + B`             | Mostrar/ocultar Barra Lateral                              |
| `Ctrl + N`             | Novo arquivo                                               |
| `Ctrl + O`             | Abrir arquivo                                              |
| `Ctrl + P`             | Ir para arquivo                                            |
| `Ctrl + S`             | Salvar                                                     |
| `Ctrl + Shift + S`     | Salvar como                                                |
| `Ctrl + F`             | Localizar                                                  |
| `Ctrl + C`             | Copiar                                                     |
| `Ctrl + V`             | Colar                                                      |
| `Ctrl + X`             | Recortar linha                                             |
| `Ctrl + Shift + K`     | Excluir linha                                              |
| `Alt + ↑ / ↓`          | Mover linha para cima/baixo                                |
| `Shift + Alt + ↑ / ↓`  | Copiar linha para cima/baixo                               |
| `Ctrl + ↑ / ↓`         | Rolar linha para cima/baixo                                |
| `Ctrl + space`         | Lista de Sugestão/AutoComplete                             |
| `Ctrl + Shift + Enter` | Inserir linha acima                                        |
| `Ctrl + Enter`         | Inserir linha abaixo                                       |
| `Alt + Clique`         | Inserir outro cursor                                       |
| `Shift + Alt + A`      | Adicionar comentário                                       |
| `Shift + Alt + F`      | Formatar documento                                         |
| `Alt + Z`              | Alternar quebra automática de linha                        |
